# ⌜ kadr ⌟

**Хватит гуглить флаги ffmpeg.**<br>
Форма в терминале, которая собирает команду ffmpeg у тебя на глазах и сама её запускает.

```
  enter пуск   ↑↓ поле   ←→ значение   tab операция   ? клавиши   esc выход
```

Ты знаешь, чего хочешь: файл поменьше, кусок из середины, только звук, gif в чат. Ты не помнишь, `-crf` там был или `-q:v` и куда ставить `-ss`. kadr это форма ровно для этого. Меняешь поле, и команда внизу меняется вместе с ним. Поле в фокусе подсвечивает свой кусок команды, так что через несколько запусков флаги запоминаются сами.

Интерфейс есть на английском и на русском. По умолчанию английский; язык переключается на странице клавиш: `?`, потом `tab`.

## Чем kadr хорош

- **Команда на экране и есть то, что запустится.** Никаких скрытых правок и временных имён. Скопируй её клавишей `c`, и она сработает в шелле как есть.
- **Каждое поле показывает свой кусок.** Фокус на `crf` подсвечивает `-crf 23`. Фокус на разрешении подсвечивает только `720` внутри `scale=-2:720`.
- **Ты видишь кадр, по которому режешь.** Кадр видео рисуется прямо в терминале, пока ты выбираешь время, даже по ssh.
- **Он не врёт про результат.** Быстрая резка начинается с ключевого кадра. kadr говорит об этом до запуска и меряет файл после.
- **Сначала читает файл.** Для исходника 720p не предложит 1080p, для ролика без звука не добавит флаги звука.
- **Убирает за собой.** Отменённый или упавший запуск удаляет недописанный файл, а ffmpeg не перезапишет ничего без твоего согласия.
- **Работает без формы.** `--print` для скриптов и README, `--run`, когда значения уже известны.
- **Работает в любом терминале.** Truecolor и графика там, где они есть, обычный ANSI и полублоки там, где их нет.

## Операции

В шелле операции называются по-английски при любом языке формы.

| Операция | Что делает | Команда за ней |
|---|---|---|
| `compress` | Уменьшает файл: h264, по желанию кадр поменьше или без звука | `-c:v libx264 -crf 23 -preset medium -vf scale=-2:720` |
| `cut` | Вырезает кусок по времени: `fast` (копия потока) или `exact` (перекодирование) | `-ss 00:00:38 -to 00:01:12 -c copy` |
| `gif` | Делает из короткого фрагмента gif с собственной палитрой | `-vf "fps=12,scale=480:-1:…palettegen…paletteuse"` |
| `audio` | Достаёт звуковую дорожку: в mp3 или как есть | `-vn -c:a libmp3lame -q:a 2` |
| `convert` | Меняет контейнер без перекодирования: mov в mp4 за секунду | `-c copy` |
| `speed` | Ускоряет или замедляет видео вместе со звуком | `-vf setpts=PTS/2 -af atempo=2` |
| `frame` | Сохраняет один кадр в png или jpg | `-ss 00:00:38 -frames:v 1` |

## Установка

kadr нужны `ffmpeg` и `ffprobe` в `PATH`.

**Из исходников**

```bash
cargo install --git https://github.com/yand3r3d3v/kadr
```

**Homebrew**

Формула, которая ставит ffmpeg вместе с kadr, готова и появится с первым выпуском. Шаги описаны в [docs/release.md](docs/release.md).

## Как пользоваться

```bash
kadr                      # выбрать файл, потом заполнить форму
kadr lecture.mov          # открыть форму на файле
```

С операцией и опциями форма откроется с заполненными полями:

```bash
kadr cut lecture.mov --from 0:38 --to 1:12
```

Или без формы:

```bash
kadr compress lecture.mov --resolution 720p --print   # напечатать команду, ничего не запускать
kadr audio lecture.mov --run                          # запустить сразу
kadr gif lecture.mov --from 0:38 --length 6 --width 320 --run
kadr frame lecture.mov --at 1:05 --run
```

Имена опций совпадают с подписями полей в английской форме, а не с флагами ffmpeg: `--resolution`, а не `--vf`. Полный список покажет `kadr <операция> --help`.

## Выбор времени

В `cut`, `gif` и `frame` рядом с полями стоит кадр видео, и он следует за временем, которое ты меняешь.

```

      ▀▀▀▀▀▀▄▄▄▄▀▀           ▀▀▄▄        ▎ курсор      00:00:41▏
             ▀▀▀▄▄▄▀▀▀▀▄▄      ▀▀▄▄        начало      00:00:38
                    ▄▄▄▀▀▀▄▄▄▄▀▀ ▀         конец       00:01:12
                            ▀▀▄▄▄▀▀▀       длина       00:00:34
  00:00:41          кадр 1026 из 3250      режим       быстро  точно

  ┣┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈[━◆━━━━━━━━━━━━━━━━━]┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┫
  00:00                00:38               01:12                           02:10
```

Двигай курсор, чтобы осмотреться; `i` делает его началом отрезка, `o` концом. Если встать на поле начала или конца, кадр покажет эту границу.

kadr спрашивает терминал, какую графику тот понимает: протокол kitty, iTerm2 или sixel дают настоящую картинку, все остальные терминалы получают полублоки, как на схеме выше. `KADR_PREVIEW=off` отключает кадр.

## Клавиши

| Клавиша | Действие |
|---|---|
| `tab` `⇧tab` | следующая и прошлая операция |
| `↑` `↓` | поле |
| `←` `→` | значение на шаг |
| `⇧←` `⇧→` или `H` `L` | на большой шаг |
| цифры | ввести значение, `enter` его берёт |
| `пробел` | следующее значение или открыть список |
| `,` `.` | на кадр назад и вперёд, в поле времени |
| `i` `o` | в `cut`: курсор становится началом, концом |
| `backspace` | вернуть значение по умолчанию |
| `enter` | запустить команду |
| `c` | скопировать команду |
| `f` | другой файл |
| `l` | показать вывод ffmpeg |
| `?` | все клавиши и переключение языка |
| `esc` | назад; из формы выход |

Буквенные клавиши работают и в русской раскладке.

## Настройки

В `~/.config/kadr/config.toml` лежат язык интерфейса и значения, с которых начинается форма. Всё в нём необязательно.

```toml
lang = "ru"          # "en" или "ru"; переключается на странице клавиш через tab

[compress]
crf = 26
preset = "slow"
resolution = "720p"

[audio]
format = "copy"      # "mp3" или "copy"

[gif]
fps = 15
width = 640
```

Значение, которое не подходит файлу, например `720p` для ролика 480p, для этого файла пропускается. Опции командной строки важнее настроек.

## Что kadr добавляет к команде

Четыре служебных флага и больше ничего: `-hide_banner -nostats -progress pipe:1`, чтобы читать прогресс, и `-n`, чтобы ffmpeg отказался перезаписывать файл, пока в команде на экране нет `-y`. На результат они не влияют.

## Про быструю резку

Копия потока может начаться только с ключевого кадра. Что это значит, зависит от контейнера:

- **mkv и другие:** результат начинается раньше, чем ты просил, с ключевого кадра.
- **mp4 и mov:** ffmpeg оставляет лишние кадры в файле и прячет их списком правок, так что плееры показывают ровно выбранный кусок.

kadr показывает, какой из двух случаев тебя ждёт, ещё до нажатия enter. Режим `exact` перекодирует и режет ровно в любом контейнере.

## Как это устроено

Операция это данные: список полей и чистая функция, которая превращает их значения в команду. Каждый кусок этой команды помнит, из какого поля он появился. Один и тот же список кусков рисуется в рамке, передаётся ffmpeg как `argv` и печатается по `--print`, поэтому они не могут разойтись.

Подробнее в [docs/architecture.md](docs/architecture.md); оформление и голос в [docs/design.md](docs/design.md). Оба документа на английском.
